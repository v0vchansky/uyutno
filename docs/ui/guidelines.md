# Гайдлайн интерфейса

Документ фиксирует решения, которые уже приняты, чтобы их не приходилось принимать заново на каждом экране. Всё, что здесь описано, лежит в токенах HeroUI (`apps/platform/src/client/theme-uyutno.css`) — правила и код расходиться не должны.

Визуальная версия документа со всеми примерами — в дизайн-файле `UI Guidelines.dc.html`.

## Отступы

Восемь значений, кратных четырём. Других в интерфейсе быть не должно: если нужное расстояние не попадает в шкалу, почти всегда неверна структура, а не число.

| px  | Где                                               |
| --- | ------------------------------------------------- |
| 4   | иконка и текст внутри кнопки                      |
| 8   | соседние кнопки, чипы, лейбл и поле               |
| 12  | горизонтальный padding поля, плотные списки       |
| 16  | поля формы между собой, карточки в сетке          |
| 24  | padding карточки, блоки внутри карточки           |
| 32  | боковые поля страницы, заголовок и контент        |
| 48  | секции лендинга между собой                       |
| 64  | крупные смысловые разделы, отбивка перед подвалом |

Два исключения:

- **6px** — между лейблом и полем ввода и между полем и подсказкой под ним: 8px там визуально рвёт пару.
- **2px** — между иконками в панели инструментов, где кнопки уже имеют внутренний padding.

**Отступы задаёт контейнер, а не элементы.** Группа однотипных элементов — это `flex` или `grid` с `gap`, не `margin-bottom` у каждого и не пустые `div`. Тогда при удалении или перестановке элемента ритм не ломается.

## Текст

Inter для всего интерфейса, Nunito 700 — только в логотипе.

| Размер | Вес       | Трекинг           | Назначение                            |
| ------ | --------- | ----------------- | ------------------------------------- |
| 44     | 600       | −0.03em           | заголовок страницы                    |
| 28     | 600       | −0.02em           | заголовок секции                      |
| 22     | 600       | −0.02em           | заголовок карточки, формы             |
| 17     | 600       | —                 | подзаголовок                          |
| 16     | 400       | —                 | вводные абзацы, line-height 1.6       |
| 14     | 400 / 500 | —                 | основной текст, лейблы полей          |
| 13     | 400       | —                 | подписи, метаданные                   |
| 12     | 400       | —                 | подсказки под полями, правовые строки |
| 11     | 600       | 0.06em, uppercase | заголовок группы в панели             |

Промежуточных размеров нет. Веса только 400, 500 и 600. Отрицательный трекинг начинается с 22px и растёт с кеглем. Строка текста не шире 620px. Абзацам — `text-wrap: pretty`, заголовкам — `text-wrap: balance`.

## Цвет

Нейтрали чисто серые, без подтона. Единственный цвет в интерфейсе — терракота, и она означает действие. Всё остальное цветное на экране должно принадлежать мебели и рендерам, а не UI.

| Токен                 | HEX     | Назначение              |
| --------------------- | ------- | ----------------------- |
| `--accent`, `--focus` | #D65400 | действия, кольцо фокуса |
| `--accent-foreground` | #FFFFFF | текст на акценте        |
| `--foreground`        | #3D3D3D | основной текст          |
| `--muted`             | #838383 | подписи, плейсхолдеры   |
| `--background`        | #F7F7F7 | фон страницы            |
| `--surface`           | #FFFFFF | карточки, поля          |
| `--surface-secondary` | #F5F5F5 | плашки                  |
| `--default`           | #F3F3F3 | вторичная кнопка        |
| `--border`            | #E4E4E4 | рамки                   |
| `--separator`         | #EAEAEA | разделители             |

**Где допустим акцент:** главная кнопка экрана, кольцо фокуса, активный инструмент, включённый переключатель, ссылка-действие. На одном экране одна главная кнопка. Вторичные действия — на `--default`, третичные — просто текстом.

Контраст терракоты с белым текстом — 4.1:1. Этого хватает для текста от 15px и полужирного от 14px, поэтому мелких надписей на акцентном фоне быть не должно.

## Форма и глубина

**Радиусы.** 8px — мелкие плитки и иконки. 12px — кнопки, поля, плашки. 24px — карточки и секции. Вся шкала выводится из `--radius: 0.5rem`; поля используют `--field-radius: 0.75rem`.

**Тени.** Две на весь продукт:

- карточки и поля — `--surface-shadow` / `--field-shadow` из темы;
- плавающие панели редактора — `0 2px 8px rgb(0 0 0 / 0.10)`.

Тени нейтральные, без тёплого подтона.

## Элементы управления

Три высоты: 36px в плотных панелях, 40px по умолчанию, 44–52px для главного действия на входе и лендинге. На сенсорных экранах ничего ниже 44px.

Поля берут геометрию из HeroUI: прозрачная рамка (`--field-border`), тень вместо обводки, радиус `--field-radius`. В фокусе — кольцо 2px акцентом, при ошибке — то же кольцо цветом danger и текст 12px под полем. Валидация срабатывает на отправке формы, а не на каждом нажатии клавиши.

Кнопкам в HeroUI жёстко задан `rounded-3xl` (24px). Нам нужны карточки 24px, но кнопки прямоугольнее, а переменными это не выражается — обе величины считаются от одного `--radius`. Поэтому в теме есть точечное переопределение `.button` в `@layer components`: 12px обычные, 14px крупные (`data-size="lg"`). Это единственное место, где тема выходит за пределы значений переменных.

## Иконки

Один набор на весь продукт — [Lucide](https://lucide.dev) (`lucide-react`). Цвет наследуется через `currentColor`, не задаётся хардкодом. Размер — prop `size`: 16 в тексте, 20 в кнопках и полях, 24 крупные (пункты меню, иллюстративные). Толщина линии по умолчанию (`strokeWidth={2}`) — оставляем, не крутим.

Свои SVG допустимы только для того, чего нет в Lucide (логотип, иллюстрации). Ставить второй icon-набор рядом — нельзя.

## Компоновка

| Тип страницы | Правила                                                                                                           |
| ------------ | ----------------------------------------------------------------------------------------------------------------- |
| Лендинг      | контент до 1200px, боковые поля 32px (16px на мобильном), секции через 48px                                       |
| Формы        | колонка 360px по центру, карточка с padding 24px, поля через 16px                                                 |
| Редактор     | рейл 60px, боковые панели по 264px, холст занимает остаток; панели не сворачиваются                               |
| Мобильный    | адаптивно всё, кроме редактора: он открывается только на компьютере, на телефоне — заглушка со ссылкой на примеры |

## Длинные списки

Бесконечная лента, не пагинация. Пока следующая порция едет — спиннер в футере ленты. Если пользователь доскроллил до конца, а загрузка ещё идёт, он должен видеть индикатор, а не пустоту.

## Текст интерфейса

| Так                             | Не так                                                    |
| ------------------------------- | --------------------------------------------------------- |
| Собрать планировку              | Начать бесплатно прямо сейчас                             |
| Проверьте адрес                 | Упс! Что-то пошло не так                                  |
| Ссылка действует час            | Ссылка будет действительна в течение 60 минут             |
| Редактор работает на компьютере | К сожалению, мы пока не поддерживаем мобильные устройства |

Обращаемся на «вы», без заглавной. Кнопка — глагол и объект: что произойдёт по нажатию. Ошибка говорит, что делать, а не извиняется. Эмодзи и восклицательные знаки не используем. Единицы всегда с пробелом: 210 × 92 см, 20,3 м².

## Если сомневаетесь

Возьмите значение из шкалы, а не среднее между двумя. Уберите элемент, прежде чем добавить новый. Цвет — последний инструмент: сначала размер, вес и расстояние. Экран должен читаться, если выключить цвет вовсе.
