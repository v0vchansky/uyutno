# Handoff · редактор планировок (планер)

Пакет по брифу `../briefs/planner-editor.md`. Приоритет P0 — конструктор стен.

## Состав

| Файл                             | Что внутри                                                                                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Planner P0 Constructor.dc.html` | DOM-прототипы P0: каркас на 1440, рейл, панель инструментов, поля ввода длины, полоса подсказки клавиш, подписи, контролы холста; плюс 15 референсных сцен холста по чеклисту 8.1 |
| `planner-editor-ui.md`           | требования к реализации DOM-части                                                                                                                                                 |
| `planner-canvas-reference.md`    | эталон холста: чертёжные токены, таблица «состояние → атрибуты», курсоры, поведение при зуме                                                                                      |
| `support.js`                     | рантайм прототипов                                                                                                                                                                |

Прототипы открываются в браузере напрямую.

## Уровень проработки

**High-fidelity** по P0: геометрия, цвета и состояния финальные. P1 (шапка, сохранение, загрузка, каталог, заглушка) и P2 (свойства, плавающая панель, линейка, подложка, walk) в этот пакет не входят — идут следующими файлами.

## Что читать до реализации

Общие правила — `../../guidelines.md`, шапки и подвалы платформы — `../../layout.md`, токены — `apps/platform/src/client/theme-uyutno.css`. Прототипы не production-код: реализация на HeroUI v3, инлайновые стили не переносятся.

## Расхождения с общими правилами

Два, оба по решениям автора и оба описаны в `planner-editor-ui.md`: своя плотная шапка редактора 48px (решение 10) и панель инструментов оверлеем поверх холста вместо колонки рейла (следствие решений 6, 8, 9).

## Новое в теме

Эталон холста предлагает восемь чертёжных токенов (`--draft-*`) — их нужно добавить в `theme-uyutno.css`. Значения и обоснование в `planner-canvas-reference.md`.
