# Handoff · Экран `/projects`

Дизайн-исходник экрана списка проектов пользователя.

- `Projects Screen.dc.html` — интерактивный прототип (`open <файл>`).
- `projects-screen.md` — требования к реализации (что рендерим, состояния, поведение, адаптив).
- `support.js` — служебный рантайм Claude Design для просмотра прототипа.

Общие правила проекта (шкала отступов, типографика, цвет, компоновка) — [`docs/ui/guidelines.md`](../../guidelines.md); шапки и подвалы — [`docs/ui/layout.md`](../../layout.md). При расхождении с описанием ниже — верны они.
