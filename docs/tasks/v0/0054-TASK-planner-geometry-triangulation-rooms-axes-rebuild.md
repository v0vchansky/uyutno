## Описание

Вторая половина геометрического ядра по принятому ADR C и первое наполнение `rebuild` шага 1: из замороженного `FloorLayout` выводятся стены-тела, комнаты и оси, а `normalize` дописывает в хранимое то, что решил ADR C (как минимум `anchor` комнат; авто-полы/зоны — по решению автора о размещении, см. эпик 0050). После задачи `manager.document.getDerived()` отдаёт настоящий `DerivedState`, а `document:changed` после любой команды планировки несёт пересобранный документ.

Скоуп (границы уточняются по ADR C, см. «Заметки»):

1. **Библиотеки** (ADR 0017 C2, спайк 0051): `cdt2d@1.0.0` и `clean-pslg@1.1.2` **точными версиями** в deps пакета; свои `.d.ts` (`declare module 'cdt2d'`/`'clean-pslg'`, `@types/*` не существуют); default-импорт CJS в ESM работает под Node/Jest(@swc/jest)/webpack SSR без правок; **клиентский webpack**: `clean-pslg` тянет `buffer` (bn.js/typedarray-pool) → alias `buffer$` на стаб `{ Buffer: { isBuffer: () => false } }` в `webpack.client.js` (запасной вариант — полифилл `buffer`, +26 KiB); что реально потребовалось — в «Заметках» (по образцу 0047).
2. **Обвязка триангуляции** (ADR 0017 C6): `triangulateContours({ outer, inner, bound, subtract, cutPairs })` — дедуп точек/рёбер hash-map по квантованному ключу, `resplitSegments` (коллинеарные осевые перекрытия/T-стыки), `clean-pslg` в чистой обёртке (копии массивов, фильтр вырожденных рёбер `[i,i]`, маппинг индексов, координаты выхода квантуются до 0.001), `cdt2d({ exterior: true })`, half-edge-lite (рёбра по отсортированной паре, `fixed`-флаг), flood-fill групп по не-fixed рёбрам **явным стеком**, sliver-safe репрезентативный треугольник (all-sliver группы отбрасываются), центроид-классификация `fill = inside(outer) > inside(inner)` с bound∩/subtract-семантикой; плоские массивы на выходе, без глобального пула.
3. **Детекция комнат** (ADR 0017 C6): `rebuildContours` — публичная чистая функция: `filterContours` → триангуляция → boundary walk каждой группы (старт min-X, виртуальная prev `[x − 10, y]`, экстремальный угол; guard `res.length > n` — признак soft-fail в результате, логирует движок), `clearDict` (dead-end вершины), повторные обходы той же группы = дырки, **нормализация ориентации** (наш `contourArea`: `outer` и обводы комнат > 0, дырки < 0), `clearContour` (5 см, коллинеарные), `contourValid`. **Классы групп:** fill — тело стены; **комната** — не-fill группа без ребра на выпуклой оболочке (ребро с одним инцидентным треугольником); остальное — exterior; дырки комнаты — по членству в группе. Контракт пригоден шагу 6 (юнион луток + число внешних контуров, Q2) и полам (bound/subtract, `separateContacting`).
4. **Оси стен** (ADR 0017 C8, оси нужны в шаге 2): `findAxes` по парам граней всех контуров (`parallelLines(PARALLEL_EPS)` → `rightOriented` → `parallelBox` 4-case, `manhDist(E, F) < L_EPS` — отказ → `boxCenterSeg` с `MAX_WALL_WIDTH = 80`/`MIN_WALL_LENGTH = 15`), ось на каждую пару по участку перекрытия, слияния нет (Q19); **направление детерминировано**: `a` = конец с меньшим `x` (при равенстве — меньшим `y`), `faces[0]` — грань слева от `a→b` (y вверх), угол — `atan2(b − a)`; выход `{ a, b, depth, faces: [{ contourId, a, b }, …] }`; индекс проём→ось — шаг 6; коннекторы — шаг 4.
5. **Пайплайн `normalize`/`rebuild`** в `engine/rebuild.ts` по ADR 0017 C1/C6/C7 (скоуп шага 2 — фазы (1)–(2) normalize и `walls/rooms/axes` rebuild; полы/зоны/cuts — 2b, коннекторы — шаг 4, проёмы — шаг 6):
   - `normalize(draft, { createId })`: (1) `rebuildContours(outer, inner, cutPairs)` → **переписать `layout.contours`/`layout.points`** результатом слияния (`outer` = обводы fill-групп, `inner` = комнаты) с дисциплиной id: вершина → id существующей точки по тождеству квантованной координаты, иначе новый id из инжектированного генератора; контур сохраняет id при той же последовательности id точек с точностью до циклического сдвига; точки без владельцев удаляются; порядок — `sortByArea`; писать в draft только при фактическом изменении; (2) пере-привязка `rooms[]` (`compareContoursByArea`, старый контур = `anchor` по координатам черновика после мутации; первый донор в порядке `rooms[]`, донор не расходуется; без донора — новая запись `{ id, anchor, name: '', ceilingHeight: settings.wallHeight }`; **записи без комнаты остаются сиротами бессрочно** — спека 02, решение автора 2026-08-19), переписать `anchor`.
   - `rebuild(snapshot)`: триангуляция нормализованного `layout` → `DerivedFloor { id, walls: { contourId, triangles: [Id, Id, Id][] }[], rooms: { contourId, roomId, outline: Id[], holes: Id[][], triangles, area }[], axes }` (треугольники — по id точек layout: Steiner-точек нет; появление вершины без id — нарушение идемпотентности normalize, ловится property-тестом); `DerivedState` заморожен, только plain-значения (0048).
   - Добавить `Contour.kind: 'outer' | 'inner'` в `PlannerDocument.ts` (ADR 0016 B3, уточнено 2026-08-19) — здесь же; `createEmptyFloor`/тесты документа обновить.
6. **Golden-фикстуры планов** (ADR 0017 C10): `packages/planner/src/document/geometry/fixtures/<case>.json` формата `{ name, input: PlannerDocument (format/version), expected: { layout: нормализованный FloorLayout, derived: DerivedFloor } }`; id детерминированные (`p1`, `c1`… — генератор инжектирован), числа с округлением до 1e-6; обновление эталона — `UPDATE_GOLDEN=1 pnpm test` с ревью диффа; стартовый набор spec-derived кейсов: 4 стены → 1 комната; самопересечение → нет комнаты; внутренняя стенка делит надвое; удалил стену — слились; комната в комнате → дырка + вложенная; висячая стена → нет ложных контуров; T-стык; вырожденная щель отбрасывается (`contourValid`); две коллинеарные короткие грани против длинной → две оси; сдвиг стены сохраняет запись комнаты (anchor переписан). **Property-тесты** `fast-check` (фиксированный seed): нет NaN/Infinity, комнаты — валидные полигоны без самопересечений и `contourValid`, ориентация выхода по контракту, `normalize(normalize(x)) == normalize(x)`, `rebuild` детерминирован, инвариантность к порядку входных контуров с точностью до перестановки комнат (донор атрибутов при перестановке может смениться — фиксируется явно).
7. **Слой 2**: транзакция `setSettings`/`load` с непустым `layout` → `document:changed` несёт пересобранный документ; `getDerived()` меняется только при изменении содержимого; ссылки неизменённых поддеревьев сохраняются.

Не в задаче: команды планировки и история (0055), снап (0057), отрисовка (0056), 3D-меши (шаг 4).
