## Описание

Минимальный UI-скин шага 2, чтобы пользователь мог пользоваться всем, что сделано в 0055–0060, без dev-ручки:

- **Панель инструментов** конструктора: «Стены», «Прямоугольная комната», «Комната по точкам» (активный инструмент подсвечен из `tools.get().kind`), кнопки **undo/redo** — зовут `tools.key({ kind: 'undo' | 'redo' })` (тот же маршрут, что клавиши, ADR 0019: в рисовании — локальный стек, в `editing` — история); disabled: в `editing` — по `history.get()` (`history:changed`), в `making-*` — по локальным стекам из `tools.get()`, тумблеры снапа `pointsSnap` / `pointsAlign` / `orthoAlign` / `bisectorAlign` (дефолты on/on/off/on), переключатель вида **конструктор ↔ 2D-план** (`view.setActive`; клик по уже активной кнопке вида — сброс камеры этого вида к дефолту, спека 08 «Смена вида» → `view.resetCamera`; в шаге 2 2D-план в Three — пустая сцена, это ожидаемо и записано в эпике).
- **Горячие клавиши здесь не вешаются**: единственный владелец клавиатуры — DOM-ввод вьювера (0056) с keymap из ADR E; панель только показывает подсказки шорткатов в тултипах кнопок (Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z, ⌘ на macOS; Esc).
- **Решения автора по дизайн-брифу (2026-08-19), входящие в скоуп:**
  - **Переключатель вида — в рейле/панели, не в шапке** (решение 8): вариант «в шапке» закрыт, монтировать сюда.
  - **Инструменты — списком «иконка + название»** (решение 6); иконки — свои SVG в метрике Lucide (24×24, та же толщина, `currentColor`), не второй icon-набор.
  - **Тумблеры снапа — иконки плюс тултип бытовой формулировкой** (решение 9); тултип `pointsSnap` обязан сказать, что выключение **сжимает радиус притяжения до 2 см**, а не отключает притяжение (спека 01 «Снап»), иначе тумблер читается как сломанный.
  - **Группа контролов холста** (решение 7) — одна полоска внизу справа поверх холста; по брифу в неё входят линейка, зум «− % +», «в центр», переключатель единиц и полноэкранный режим. **В шаге 2 наполняются зум, «в центр» и единицы; место под линейку и полноэкранный режим закладывается пустым** (линейка — шаг 8). Зум наполняется публичным шагом шкалы, который выводит наружу 0056; «в центр» — `fitToContent()` проекции.
  - **Переключатель единиц `см / м / мм`** (решение 15) — здесь, а не в отложенных «Настройках проекта»; пишет `document.setSettings({ units })`. **Имперской системы нет** (решение 18): в `UNITS` её больше не существует.
  - **Контекстная подсказка горячих клавиш** (решение 3) — отдельный компонент оболочки, узкая полоса по нижнему краю холста, источник — `tools:changed { state: ToolState }`; монтируется здесь, 0060 её не дублирует. Состояния автомата: `editing` (в т.ч. «подсказки нет»), `making-walls`, `making-rect`, `making-room`, `dragging-point`, `dragging-wall`. **Два случая автомат не различает — «фокус в поле длины» (ключевой, ради которого компонент и вводится: «Tab — другое поле», «Enter — поставить точку») и «выделено ребро/стена»: их источник — оверлей инпутов 0060.** Значит компонент принимает подсказку из двух источников, а не только из `tools:changed`; конкретный механизм (второе событие шины vs проп от оверлея) решается вместе с 0060 при реализации — состояние инпутов там ещё открыто («`ToolState` или локально в `ui` — по ADR E»). Не больше трёх пар «действие → клавиша» одновременно, переполнение — обрезка по приоритету, не перенос строки. Это снимает парковку build-order «Контекстная подсказка горячих клавиш».
  - **Место под панель статистики** (решение 11) — угол холста зарезервировать в раскладке, содержимое не наполнять.
- **Раскладка** в `<Planner />` по ADR E (панели как `children` рядом с канвасами или оверлеи в контейнере) и монтирование на `/project/:id` без изменений `ProjectPage` сверх раскладки; SSR — панели рендерятся только после подъёма движка (0048: дети — внутри контекста).
- Все действия — только через фасад (ADR 0015 A2); React состояние документа не хранит.

Тесты: jsdom — кнопки зовут команды фасада, disabled по `history.get()`, активный инструмент по `tools.get()`, повторный клик по активному виду → `resetCamera`; Playwright: e2e-смоук шага 2 **через UI** (кнопка «Прямоугольная комната» → два клика → комната → Ctrl+Z → Ctrl+Y) и визуальная приёмка на 1440 по макету (планер desktop-only; 768 / 390 — только что панель не ломает вёрстку страницы).

Не в задаче: панель свойств комнаты, каталог, инспектор (шаги 5/7); кнопки 3D/walk (шаги 4/9).

- [ ] Группа контролов холста внизу справа: зум «− % +» на публичном шаге шкалы из 0056, «в центр», переключатель единиц `см / м / мм`; места под линейку, полноэкранный режим и панель статистики зарезервированы и пусты.
