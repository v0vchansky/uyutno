## Описание

Прошить ссылки на `/terms` и `/privacy` во все места сайта, где они по макетам должны присутствовать. В футере `PublicLayout` (задача 0004) ссылка `/terms` уже нарисована — надо убедиться, что она действительно ведёт на страницу из 0017, и добавить `/privacy` (там, где по макетам она должна быть — сейчас в футере только `/terms`, но при появлении реальной страницы приличная политика конфиденциальности рядом с условиями — стандарт; уточнить с макетом). Константы `TERMS_URL`/`PRIVACY_URL` в `src/client/common/` уже заведены задачей 0013 (первое использование — правовая строка регистрации) — эта задача переиспользует их.

Скоуп:

- Обновить футер `PublicLayout`: заменить хардкод `/terms` на константу `TERMS_URL`; добавить ссылку `/privacy` рядом через `PRIVACY_URL` (по образцу существующей ссылки в макете).
- Пройтись по остальным местам сайта (если появятся) и убедиться, что все правовые ссылки идут через общие константы.

Вне скоупа:

- Реальные тексты страниц (в 0017).
- Форма регистрации (в 0013) — она уже использует эти константы.

### Приёмка UI (Playwright MCP)

- Открыть любую публичную страницу (например, `/`), кликнуть по ссылкам в футере на `/terms` и `/privacy` — убедиться, что открываются реальные страницы из 0017.
- Прогон на 1440 / 768 / 390.
