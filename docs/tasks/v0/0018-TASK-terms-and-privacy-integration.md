## Описание

Прошить ссылки на `/terms` и `/privacy` во все места сайта, где они по макетам должны присутствовать. В футере `PublicLayout` (задача 0004) ссылка `/terms` уже нарисована — надо убедиться, что она действительно ведёт на страницу из 0017, и добавить `/privacy` (там, где по макетам она должна быть — сейчас в футере только `/terms`, но при появлении реальной страницы приличная политика конфиденциальности рядом с условиями — стандарт; уточнить с макетом). В правовой строке формы регистрации (задача 0013) ссылки на `/terms` и `/privacy` берутся из общей точки.

Скоуп:

- Единая точка для ссылок: константы `TERMS_URL = '/terms'`, `PRIVACY_URL = '/privacy'` в `src/client/common/` — чтобы будущие изменения роутов не размазывались по коду.
- Обновить футер `PublicLayout`: убедиться, что `/terms` ведёт на реальную страницу; добавить `/privacy` рядом (по образцу существующей ссылки на `/terms` в макете).
- Экспортировать константы из `common`, чтобы 0013 могла на них сослаться в правовой строке.

Вне скоупа:

- Реальные тексты страниц (в 0017).
- Форма регистрации (в 0013) — эта задача только предоставляет константы.

### Приёмка UI (Playwright MCP)

- Открыть любую публичную страницу (например, `/`), кликнуть по ссылкам в футере на `/terms` и `/privacy` — убедиться, что открываются реальные страницы из 0017.
- Прогон на 1440 / 768 / 390.
