## Описание

Сверяем текущие секции лендинга (`HomePage`, `HeroSection`, `FeaturesSection`, `HowItWorksSection`, `UseCasesSection`, `FaqSection`, `FinalCtaSection`) с обновлённым макетом `Landing.dc.html` и подтягиваем всё, что разошлось: типографика, отступы, композиция, порядок секций, оформление CTA и плейсхолдеров скриншотов. Реальные скриншоты не подставляем — это отдельная задача 0003; пока живём с плейсхолдерами, но их вид тоже приводим к макету.

Границы скоупа:

- **В скоуп входит:** содержимое `<main>` на `/` во всех трёх размерах (1440 / 768 / 390) — вёрстка, стили, тексты, если они разошлись со спекой.
- **Вне скоупа:** шапка/подвал (уже сделаны в 0026), реальные скриншоты (0003), пример проекта (`/demo`).

## Приёмка

- [x] Каждая секция лендинга визуально сходится с соответствующим блоком `Landing.dc.html` на 1440 / 768 / 390.
- [x] Отступы, размеры шрифтов, цвета — из `docs/ui/guidelines.md`, без «средних» значений.
- [x] Тексты и порядок секций совпадают с макетом (или отступление явно зафиксировано в «Заметках» с причиной).
- [x] Playwright MCP: `/` на 1440 / 768 / 390, скроллом проходим все секции.

## Заметки

- Точка перелома — одна, 1024px (`lg`), согласно гайдлайну. Промежуточные `md:`-варианты типографики убраны: заголовки h1/h2 переключаются 22/28 и 28/44 без промежуточных «средних» кеглей.
- До 1024px колонка контента лендинга ограничена 560px и центрируется (`max-w-[560px] lg:max-w-[1200px]`) — исполнение правила из «Компоновка · Планшет» в `docs/ui/guidelines.md`.
- HTML-макет `Landing.dc.html` содержит только кадры 1440 и 390; 768 верифицирован по гайдлайну (см. выше).
- Плейсхолдеры оставлены как есть (задача 0003), но их геометрия и подписи приведены к макету.
