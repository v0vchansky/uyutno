## Описание

Первый инструмент планера, полностью headless: неймспейс `tools` фасада с единственным автоматом по ADR E (idle-хаб `Editing` + под-состояния), **контракт ввода** — команды фасада с координатами **плана** (`pointerMove/Down/Up`, `pointerCancel`, `blur`, `key`), без DOM (DOM-слушатели и пересчёт экран → план — вьювер 0056), и инструмент **«Стены»** (polyline с лентой): клик ставит точку (снап 0062 применён — первая точка снапнута к моменту клика), лента `DEFAULT_WALL_WIDTH = 10` с авто-выбором стороны до третьей точки, замыкание (евклид: ≤ толщины к последней / ≤ `CLOSE_EPS` к первой), dblClick — no-op, Esc — отмена, Ctrl+Z — снять предпоследнюю точку из локального стека (история документа не тронута), «до пустого холста» — выход из рисования, коммит контура одной транзакцией (0055) — стены с толщиной и комната появляются в `getDerived()`. Гайды снапа, крест и live-превью ленты (0053) — часть `ToolState`; их рисует 0056.

Скоуп (по ADR E/D, границы уточняются — «Заметки»):

1. `engine/tools/` (или по ADR E): типизированные состояния (discriminated union), `tools.get(): ToolState` (активный инструмент, фаза, точки рисуемого контура, снап-результат/гайды, hover/выделение конструктора), `start/cancel/finish`, обработчики ввода как команды с координатами плана и модификаторами (Ctrl/Cmd как выключатель снапа — заложить), событие `tools:changed` (частота — по ADR E); флаги снапа `pointsSnap/pointsAlign/orthoAlign/bisectorAlign` — там, где решил ADR E; реакция на `view.setActive`, `document.load`, undo при зажатой кнопке, `dispose` — по ADR E; снятие выделения по событию/методу истории (имя — ADR D).
2. Инструмент «Стены» по спеке 01 «Polyline Walls» + «Крайние случаи» (короткий последний сегмент, дубли, самопересечение — молчаливый отказ; T-стык-старт на существующей стене — из 0053; открытая полилиния — по решению ADR E), снап на каждом `pointerMove` через 0062 с индексом кандидатов, `exceptPoints`, куллинг по видимой области (границы — параметр от вьювера в `ToolState`/команде).
3. Тесты слоя 2 (фасад как state-машина): все переходы (`start` → точки → замыкание → коммит; Esc; Ctrl+Z до пустого холста → выход; `blur`/`pointerCancel` во время рисования; выход указателя за канвас; смена инструмента посреди действия; dblClick — no-op; `view.setActive`/`load` посреди рисования), `history` не тронута до коммита, ровно одна запись на коммит, `tools:changed` по правилу ADR E; e2e через dev-ручку `onReady`: `tools.start('walls')` + синтетические команды с координатами плана → комната в `getDerived()` → undo/redo.

Не в задаче: снап-функции и индекс (0062); DOM-ввод, гайды/отрисовка (0056); «Прямоугольная комната», «Комната по точкам» (0058); правка точек/сегментов (0059); live-инпуты (0060); панель (0061).

## Заметки

- Скоуп заведён до принятия ADR D/E (0052); после принятия — сверить форму `tools`, где живут флаги снапа, частоту `tools:changed`, судьбу live-превью (документ не трогается до коммита — или иначе), поведение на смену вида/загрузку и поправить этот файл. Снап вынесен в 0062, DOM — в 0056, чтобы эта задача была design-free и влезала в один PR.
- **Уточнено по ADR 0019/0018 (2026-08-19):** `ToolState` — discriminated union по `kind` (`editing` / `making-walls` / `making-rect` / `making-room` / `dragging-point` / `dragging-wall`), общие поля `snapFlags`, `viewport`; команды `start/cancel/interrupt/pointerDown|Move|Up(input: PointerInput)/doubleClick/pointerCancel/blur/key(action)/commitPoint/setSnapFlags/setViewport`; **`tools:changed` — на каждое изменение состояния, включая `pointerMove`**; `key({ kind: 'undo' | 'redo' })` в рисовании — локальный стек, в драге — отмена жеста, в `editing` — `history.undo()/redo()` (кнопки панели 0061 идут этим же маршрутом); `interrupt()` — по хуку `StoreHooks.beforeReplace` (undo/redo/`load`) и при `view:changed` вне конструктора (рисование отменяется, выделение сохраняется); **«Стены»: клик у последней точки (≤ ширины, евклид) коммитит открытую полилинию, у первой (≤ `CLOSE_EPS`) — замкнутую, Esc — отмена; после коммита — `editing`**; коммит — `document.addContours` N `outer`-квадов (0055); отказы молчаливые (`logger.debug`). Своя машина на discriminated union с одной точкой перехода, без xstate.
- **Реализовано (2026-08-19).** Раскладка `engine/tools/`: `ToolState.ts` — типы (`ToolState = { snapFlags, viewport } & (EditingState | MakingWallsState)`, `HitTarget`, `PointerInput`, `KeyAction`, `DrawingTool`, `DEFAULT_VIEWPORT`); `ToolHandler.ts` — контракт обработчика состояния (`ToolContext`, `Step { state, effect? }`, `KeyStep`, `PlaceStep`), таблица `ToolHandlers`; `editing.ts` / `makingWalls.ts` — обработчики; `ToolsNamespace.ts` — неймспейс фасада: единственная точка перехода `transition` (та же ссылка варианта = no-op; иначе новый замороженный снимок → `breakSeries` при смене выделения → `tools:changed` → отложенный `effect`), таблицы `HANDLERS`/`STARTERS` (новое состояние 0058/0059 = член union + обработчик [+ стартер], автомат не меняется), подписки на `view:changed` (вне конструктора → `leaveConstructor`) и `document:changed` (пересчёт снапа по свежему индексу), свой `SnapCandidateIndex`. Публичный API: `get()`, `start('walls'): Result<void, StartToolError>` (`unknown-tool` / `view-not-constructor` / `no-active-floor`), `cancel()`, `interrupt()`, `pointerDown/Move/Up/doubleClick(input)`, `pointerCancel()`, `blur()`, `commitPoint(point): Result<void, CommitPointError>` (`invalid-point` / `not-drawing` / `too-short` / `duplicate-point`), `key(action): { handled }`, `setSnapFlags(patch)`, `setViewport(v): Result<void, SetViewportError>`, `dispose()`. Событие `tools:changed { state }` — на каждое изменение (включая `pointerMove`, `setViewport`, `setSnapFlags`), ни одного на no-op (дубль `pointerMove`, равный viewport, повтор флагов; кадр рисования сравнивается по значению). `PlannerManager`: хук `beforeReplace` → `tools.interrupt()`, `tools.dispose()` в `dispose()`; `index.ts` — типы `ToolState`/`SnapFlags`/`SnapResult`/`Viewport`/`SnapGuide`/… Правки в `document/`: экспорт `missSnap(raw)` из `getSnapPoint.ts` (снап выключен — Ctrl/Cmd).
- **Решения в рамках/сверх ADR (вписаны в ADR 0019 «Что важно знать»):** `cursor`/`snap` — `null` до первого ввода указателя, `guides` и `startNeighbours` — в состоянии; точку ставит `pointerUp` основной кнопки (`pointerDown` — только снап; `pointerUp` без `pointerDown` тоже ставит — как референс, `armed`-трекинг не заводили); `blur`/`pointerCancel` в `making-walls` — no-op (точки остаются; спека 09 про drag); реальный двойной клик = второй `pointerUp` у последней точки = завершение открытой ленты (как roomtodo), команда `doubleClick` — no-op — **развилка автору/0056**: если продукт хочет буквально «второй клик двойного игнорируется», вьювер фильтрует `pointerup` с `event.detail > 1`; гард входа при постановке точки (ребро < `MIN_WALL_LENGTH`, в т.ч. замыкающее; дубль точки) — молчаливый игнор с `logger.debug`, `commitPoint` отдаёт причину; зона `width < d < 15` от последней точки — тоже игнор; при двух точках клик в первую — дубль, не петля (петля от трёх точек; референс завершил бы рисование); Ctrl+Z при пустом стеке — no-op (кнопка disabled по стеку, ADR E3), при снятии последней точки → `editing` (спека 09); Ctrl+Z/Ctrl+Y/nudge — через обработчик состояния, Esc — генерически (`key({kind:'cancel'})` = `cancel()`); `start` вне конструктора/без этажа — ошибка `Result`; смена инструмента посреди рисования — один переход и одно событие (промежуточного `editing` нет); коммит (`addContours`) — отложенный `effect` после перехода в `editing`, поэтому порядок событий: `tools:changed` (editing) → `document:changed`; Ctrl/Cmd выключает снап целиком и в рисовании; выделение при `start` снимается (рисование и выделение конструктора взаимоисключающие) — `breakSeries`; `DEFAULT_VIEWPORT` 1024×768 при `scale = 1`, центр `(0,0)`. `finish()` из старого скоупа не заводился — отдельного шортката завершения в v0 нет (спека 01). «Выход указателя за канвас» отдельной командой не нужен: без зажатой кнопки — просто нет `pointerMove`, с зажатой — `setPointerCapture` вьювера (E5). Открытая развилка 0062 (куллинг режет draft-кандидаты своего контура за кадром) — не решалась.
