## Описание

Каждая страница должна рендерить свои `<title>` и `<meta name="description">` — React 19 сам поднимает их в `<head>`. Правило уже зафиксировано в [`apps/platform/src/client/CLAUDE.md`](../../../apps/platform/src/client/CLAUDE.md) в разделе «Страницы (`pages/`)», но:

- нужен аудит, что все существующие страницы под правило действительно попадают (текущий список: `HomePage`, `LoginPage`, `RegisterPage`, `ProjectsPage`, `ProjectPage`);
- правило нужно поднять на уровень доски задач (`docs/tasks/v0/README.md`, раздел «Правила ведения»), чтобы автор задачи, заводящий новый экран, видел его при постановке задачи, а не только когда доходит до `src/client/` кода;
- заодно пройтись по текстам `title`/`description` и убедиться, что они осмысленные и уникальные (не заглушки, не дубли).

## Скоуп

1. **Аудит существующих страниц.** Пройтись по всем `apps/platform/src/client/**/pages/**/*Page.tsx`:
   - У каждой в JSX должны быть `<title>` и `<meta name="description">` (не в лэйауте, не в шаблоне — прямо в странице, чтобы дефолта не было).
   - Тексты должны отражать реальный смысл страницы, а не быть плейсхолдерами.
   - Если чего-то не хватает — дописать; тексты согласовывать по здравому смыслу, без изобретения оффера или обещаний, которых нет в спеке.
2. **Правило в доске задач.** В [`docs/tasks/v0/README.md`](README.md), в блоке «Правила ведения», добавить отдельный пункт (например, рядом с «Дизайн» и «Приёмка UI-задач»): «**Мета для страниц.** Любая задача, которая заводит новую страницу (`pages/*Page.tsx`), обязана в приёмке проверить наличие `<title>` и `<meta name="description">` у этой страницы. Правило раскрыто в [`apps/platform/src/client/CLAUDE.md`](../../../apps/platform/src/client/CLAUDE.md#страницы-pages)». Формулировку можно доработать, но идея — сделать требование видимым на уровне доски.
3. **Сверка формулировок.** Убедиться, что правило в `apps/platform/src/client/CLAUDE.md` и в `docs/tasks/v0/README.md` не расходятся: единственный источник правды по деталям — `CLAUDE.md`, README должен ссылаться, а не переписывать.
