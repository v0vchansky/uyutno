## Описание

Два оставшихся инструмента контура шага 2 на каркасе 0057 (тот же автомат, тот же снап, тот же коммит одной транзакцией):

- **«Прямоугольная комната»** (спека 01 «Rectangle Room»): первый клик — угол, движение мыши тянет живой прямоугольник, второй клик — противоположный угол и автозавершение; если обе стороны > 2 × `DEFAULT_WALL_WIDTH` — полая комната (внешний + внутренний контур, 8 точек), иначе сплошной 4-точечный контур; превью — из ленты 0053; live-инпуты размеров (≥ 70 px) — 0060.
- **«Комната по точкам»** (спека 01 «Polyline Room»): контур без толщины, каждый клик — вершина, замыкание — слияние очередной точки с ближайшей уже поставленной по манхэттену в пределах эпсилона; минимум 4 точки; `contourValid`/самопересечение — молчаливый отказ; Esc/Ctrl+Z — как у «Стен».

Скоуп: два под-состояния автомата, превью и гайды через `ToolState`, коммит через команды 0055; тесты слоя 2 — все переходы обоих инструментов (обе ветки полая/сплошная у прямоугольника — обе стороны порога 2×толщины; < 4 точек; самопересечение; Esc; Ctrl+Z до пустого холста; blur; смена инструмента посреди действия); golden-кейс «прямоугольник 300×400 → полая комната площадью …» в фикстурах 0054 при необходимости; **e2e-смоук шага 2 через dev-ручку** (эпик 0050): `tools.start('rect')` → два клика → комната в `getDerived()` → undo → redo.

Не в задаче: инструменты «Зона» и «рисование пола» (по решению автора о размещении — эпик 0050 «Заметки»); правка (0059); инпуты (0060); кнопки (0061).
