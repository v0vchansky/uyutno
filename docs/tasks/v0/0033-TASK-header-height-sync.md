## Описание

Шапка (`apps/platform/src/client/common/components/PublicLayout/PublicHeader.tsx`) на разных страницах сейчас разной высоты: на `/login` и `/register` в шапке только логотип (~20px + padding 12+12 = ~44px), а на лендинге и в `/projects` — контентная строка на 40px + padding = ~64px. Из-за этого при переходе «/» → «Войти» страница «дёргается» на десятки пикселей.

Дизайн уже обновлён: высота содержимого шапки **фиксируется через `min-height`** — 40px на десктопе, 44px до 1024px (мобилка/планшет) — независимо от того, что внутри. См. обновлённые макет и доку.

## Скоуп

**Клиент (`apps/platform/src/client/`):**

1. **`PublicLayout/PublicHeader.tsx`.** Внутреннему контейнеру шапки задать `min-h-10 lg:min-h-10` (40px) — а на мобилке 44px (`min-h-11`). То есть `min-h-11 lg:min-h-10`. Это гарантирует единую высоту всех четырёх состояний (`guest-landing`, `auth-landing`, `app`, `auth`).

2. **Sanity-check `padding`.** По макету — `padding: 12px 32px` на десктопе, `12px 16px` до 1024px, что уже соответствует текущему `px-4 py-3 lg:px-8`. Проверить, что не сбилось.

3. **`scroll-padding-top` в `global.css`.** Сейчас 65px — соответствует десктопу (12+40+12+1). На мобилке — 69px (12+44+12+1). Если получится вписать через media-query аккуратно, сделать; иначе оставить единое 69px (пятипиксельная разница на десктопе не критична и не ломает якорные переходы).

4. **Документация.** `docs/ui/layout.md` уже обновлён с фиксацией высот; ничего в нём менять не нужно. Только сверить с текущим кодом, чтобы не разошлось.

## Заметки

- Итоговое решение — `min-h-[68px] lg:min-h-16` вместо `min-h-11 lg:min-h-10` из скоупа. В проекте глобально `box-sizing: border-box`, поэтому `min-height` считает **вместе с padding**. На «пустой» шапке (только логотип 20px) `min-h-10` = 40px не растянула бы box до нужных 64px, потому что фактическая высота 20+24 = 44 > 40 и минимум игнорируется. Правильный ориентир — итоговая высота box'а: 64px на десктопе (`min-h-16`) и 68px до 1024px (`min-h-[68px]`); плюс 1px `border-b` на самом `<header>` дают целевые 65px / 69px из `docs/ui/layout.md`.
- `scroll-padding-top` разнесён через media-query 1024px: 69px по умолчанию, 65px на десктопе. Совпадает с реальной высотой sticky-шапки, якорные переходы (`#faq` и т.п.) встают ровно под шапку.
- Проверка `/projects` требует активной сессии — при отсутствии кред опущена. Реализация не разделяет `PublicHeader` по mode на уровне контейнера, поэтому расхождения быть не может.
