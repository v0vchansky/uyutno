## Описание

Активные подписи длин над рёбрами по спеке 01 «Ввод размеров с клавиатуры»:

- **При рисовании** («Стены», «Прямоугольник» — 0058): поверх каждого ребра — длина; если ребро на экране ≥ 45 px (полилиния) / ≥ 70 px (прямоугольник) — это инпут (26 px, повёрнут под углом ребра — спека 07); при > 2 точках — второй инпут для первой точки («отращивать контур с обратной стороны»), у прямоугольника — два инпута W/H (спека 07); появляются/исчезают по видимости (пересчёт при зуме/пане через `planToView` 0056), значение переживает скрытие; Tab — по кругу между видимыми инпутами; **Enter = постановка точки** тем же `commitPoint()`, что и клик, с тем же правилом замыкания (Q27); формат — только абсолютная длина; Esc в инпуте — отмена ввода (спека 07).
- **При правке** (выбрано ребро/стена из 0059): инпут длины ребра (`N`, `+N`, `−N`; оба конца симметрично ±дельта/2) и инпут ширины стены (оба конца перпендикулярно ±дельта); отказ при самопересечении или < 15 см, `0` — «слишком мало»; коммит через команды 0055 (одна запись истории на Enter/blur/Tab — coalescing по спеке 09).
- **Парсинг/ошибки**: пустое, отрицательное где нельзя, мусор, > 100 000 см — отклоняются с локализованным сообщением; `toFixed` без научной нотации; единицы документа (`settings.units`) — форматирование/парсинг по спеке 07 в объёме, нужном инпуту (см/м/мм/футы — по ADR E решить, что в шаге 2, что в шаге 8).
- **Фокус и клавиши**: пока фокус в инпуте — глобальные клавиши редактора (Esc/Ctrl+Z/стрелки) не перехватываются; стрелки в инпуте — браузерные.

Скоуп: React-компонент оверлея в `ui/` (что из спеки 07 «Правка размера по клику»/«Автоматические размеры на стенах» входит сюда, а что — в шаг 8, решает ADR E; по умолчанию здесь — всё, что относится к рисованию/правке рёбер конструктора) (позиционирование по `planToView` + поворот к ребру, `z-index` над канвасами), состояние инпутов (`ToolState` или локально в `ui` — по ADR E), парсер/форматтер как чистые функции с тестами (обе стороны каждого порога 45/70 px, лимит 1 км, `+N/−N`, `0`, дробные, единицы), тесты слоя 2 на Enter = `commitPoint` с замыканием и на отказы, jsdom-тест компонента (показ/скрытие по порогу, Tab по кругу), визуальная приёмка через Playwright MCP.

Не в задаче: линейки и глобальный переключатель единиц (шаг 8); панель свойств.
