## Описание

Свёрстать главную страницу `/` по макету `docs/ui/handoffs/auth/Landing Simple.dc.html`.

Реализуем на компонентах HeroUI v3 и токенах темы из `apps/platform/src/client/theme-uyutno.css`, а не переносим инлайн-CSS из `.dc.html` (см. `docs/ui/handoffs/README.md`). Правила отступов, типографики и компоновки — по `docs/ui/guidelines.md`; при расхождении с handoff-README верен гайдлайн.

**Адаптивная вёрстка обязательна.** Лендинг — точка входа для органического трафика и напрямую влияет на SEO-ранжирование и отказы (см. `docs/product/release-v0.md` «Технические ограничения»). Макет `Landing Simple.dc.html` содержит **три размера — десктоп (1440), планшет (768) и телефон (390)** (см. `docs/ui/handoffs/auth/README.md` → таблица Files); все три реализуем по макету, а не изобретаем собственные брейкпоинты и раскладку.

Скоуп задачи — только разметка и стили страницы `/`:

1. **Hero** — заголовок, описание, две CTA-кнопки (`/register`, `/demo`), маркеры («Без оплаты», «Сколько угодно проектов»), скриншот 3D-вида справа.
2. **«Что внутри»** — заголовок секции + подзаголовок + сетка из трёх карточек (первая — широкая с 2D-планом, две узкие — «каталог мебели» и «вид в 3D»).
3. **«Как это работает»** — заголовок + три пронумерованных шага-карточки.
4. **«Когда пригодится»** — заголовок + три карточки сценариев.
5. **FAQ** — заголовок + подзаголовок + аккордеон из 4 вопросов (первый открыт по умолчанию).
6. **Финальный CTA** — заголовок «Попробуйте на своей квартире» + подзаголовок + кнопка «Создать проект».

Условия:

- Страница обёрнута в общий публичный layout из задачи 0004 (Header + Footer в этой задаче не верстаем).
- CTA ведут на `/demo` и `/register` (роуты могут ещё не существовать — ставим ссылки как есть, без обработки 404).
- Якоря `#features`, `#how`, `#faq` совпадают с ссылками в Header из макета — использовать те же id.
- Скриншоты редактора и иллюстрации сценариев — **плейсхолдеры** с явной пометкой (в разметке/`alt`), чтобы задача 0003 нашла их без поиска. Реальные скриншоты — отдельная задача 0003.
- FAQ реализуем через HeroUI Accordion, а не `<details>`.

Вне скоупа: SSR, мета/OG-теги, sitemap, structured data, семантические микроразметки — они в разделе «SEO-техническая база».

## Заметки

Сверх заявленного скоупа добавили минимальную мету и фавиконки для страницы `/`: `<title>`, `<meta name="description">`, `<meta name="theme-color">`, `<link rel="icon">` (SVG 32×32 и 16×16) и `<link rel="apple-touch-icon">`.
