## Описание

Снап как чистая математика, отдельно от автомата (0057) и от отрисовки (0056), чтобы влезть в один PR и покрыться слоем 1 целиком:

1. **`document/geometry/snap/`** — чистые функции над плоскими массивами кандидатов (без импорта `engine/`, ADR 0015 — слои), на предикатах 0053: `snapX`/`snapY` (по два кандидата на ось — полуплоскости, ключ по оси затем вдоль с `L_EPS`, отсечка `> snapDist`, взаимное отсечение в `B_EPS`, обе могут выжить), `snapPerpendicular` (представитель оси — ближний по манхэттену; координаты поосно; сырые пары для расширенных гайдов), `snapToNearest`/`findNearest` (манхэттен), `orthogonalSnap` (оси через предпоследнюю и первую точку контура, ≥ 2 точек), `bisectorSnap` (радиус ×10, соседи по кольцу, `bisectorPoint`, отказ по перпендикулярной дистанции), `findNearSegments`; лесенка `getSnapPoint` из 8 веток с приоритетом Y (спека 01 «Приоритет», README) и радиусом угла 2 см при `pointsSnap=off`; результат `{ snapped, alignerX, alignerY, bisAnchor, rawAlignersX, rawAlignersY }` + описание гайдов для отрисовки (правила подавления: совпадение с выравнивателем в `B_EPS`, точка на стене, угловой фильтр ≈ 135°, T-стык — только основной снап); квантование результата 0.001; **метрика** по спеке 01: манхэттен для приёма любого точечного снапа (угол, биссектриса), евклид — радиус поиска угла ×10; пороги — параметры функции в единицах плана (px → план делает вызывающий), `exceptPoints`, `viewport` — обязательный параметр (куллинг всегда on, спека 01).
2. **Индекс кандидатов в `engine/`** — производный от документа/`DerivedState`: пул = вершины комнат + точки рисуемого контура + вершины полов (аудит dd09 keep); пересборка по `document:changed`; глобалов/синглтонов нет; grid-снапа нет (Q18).
3. **Тесты слоя 1** («вся математика и все ветки»): каждая ветка лесенки, обе стороны каждого порога (`SNAP_DIST`, 2 см, ×10, `B_EPS`, `L_EPS`), приоритет Y при одновременных X/Y, куллинг (кандидат за вьюпортом не снапит), `exceptPoints`, все четыре флага on/off, вырожденные входы (пустой пул, совпадающие точки, `NaN`), tie-breaking `snapX/snapY` (оба выживают); property-тест: результат всегда квантован и внутри радиуса либо равен сырому курсору.

Не в задаче: автомат и коммиты (0057), отрисовка гайдов (0056), хит-тест правки (0059 — но `findNearest`/пороги переиспользуются).
