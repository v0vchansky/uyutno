## Описание

Пришёл обновлённый пакет макетов. У шапки теперь четыре состояния (гость на лендинге / вошедший на лендинге / приложение `/projects` / авторизация), появилось меню профиля с аватаром-инициалами и шевроном, а до 1024px навигация и профиль уходят в бургер, который **накрывает** контент (не сдвигает), с затемнением 40% и `overflow: hidden` на `body`. Подвал теперь тоже вариативный: развёрнутый на лендинге (четыре колонки, `--surface-secondary`, ссылки на разделы, аккаунт, поддержку) и служебная строка в приложении/авторизации. В авторизации в шапке только логотип, в подвале — только правовая строка по центру.

Экраны лендинга и `/login`, `/register` тоже перерисованы — сверить с новыми `.dc.html` и подтянуть, где расходится с текущей вёрсткой. Экраны `/forgot-password` и `/reset-password` в скоуп эпика не входят: их вёрстку делает [0014](0014-TASK-password-reset.md) одновременно с бэком (сейчас страниц просто нет — сверять нечего).

Текущий `PublicHeader` знает только два состояния (гость / вошедший) и всегда рендерит одну панель — под все четыре состояния макета этого мало. `PublicFooter` — одна строка ссылок на всех страницах, тоже не соответствует. Эпик покрывает и переделку `PublicLayout`, и синхронизацию страниц.
