## Описание

Режим правки — idle-хаб автомата 0057 (`Editing`) и два drag-состояния по спеке 01 «Редактирование»:

- **Хит-тест по приоритету** при наведении: угол (`POINT_SIZE / scale`) → сторона стены (`SNAP_DIST / 2 / scale`, `pointOnSegment`) → область; hover-подсветка в `ToolState` (рисует 0056).
- **Выбор**: клик по точке — точка, по стороне — стена, Ctrl+клик по стороне — вся комната; клик мимо — сброс; Esc — сброс. Где живёт выделение конструктора — по ADR E (`Editing`-состояние или `selection`).
- **Драг точки** после сдвига > 3 px (одна константа порога): снап с `exceptPoints` = перетаскиваемая точка (+ совладельцы общего id — они едут автоматически); live-позиция — в состоянии инструмента (документ не трогается до mouseUp — по ADR D/E); на mouseUp — команда `movePoints` одной записью истории; **дроп на стену** → разрез стены точкой (`splitSegment`), **дроп на точку** (манхэттен < эпсилона) → слияние (`mergePoints`) — координата после снапа финальная, без «прыжка».
- **Драг стены** по нормали: дельта курсора проецируется на перпендикуляр, оба конца сдвигаются одинаково; гайды подавлены, снап позиции учитывается; mouseUp — `moveSegment`.
- **Удаление точки** двойным кликом → `deletePoint` (слияние двух смежных стен; общий id — правило ADR D).
- **Прерывание**: Esc во время драга / blur вкладки / `pointercancel` → возврат к исходному положению, в историю ничего не пишется.
- **Если решено ADR E** (иначе — шаг 8 / вопрос автору): нудж выделенной точки стрелками на шаг единицы (спека 01 «Клавиши в инпуте»: 1 см / 0.1 см / 1.27 см, Shift ×10, Shift+Ctrl ×0.1) — команда `movePoints` с coalescing серии; удаление выбранной стены целиком (Delete).

Скоуп: состояния и переходы, хит-тест как чистые функции (`document/geometry/` или рядом со снапом), связка с командами 0055; тесты: слой 1 — хит-тест по приоритету и обе стороны каждого порога (`POINT_SIZE`, `SNAP_DIST/2`, 3 px), проекция дельты на нормаль; слой 2 — все переходы (hover → выбор → драг → дроп; дроп на стену → разрез; дроп на точку → слияние; dblClick → удаление; Esc/blur/`pointercancel` во время драга → откат без записи; смена инструмента посреди драга); одна запись истории на жест; e2e через dev-ручку: нарисовать прямоугольник → перетащить угол → комната пересобрана → undo вернул.

Не в задаче: инпуты длины ребра / ширины стены (0060); панель свойств комнаты (шаг 7); DOM-ввод и отрисовка hover/выделения (0056).
