## Описание

Режим правки — idle-хаб автомата 0057 (`Editing`) и два drag-состояния по спеке 01 «Редактирование»:

- **Хит-тест по приоритету** при наведении: угол (`POINT_SIZE / scale`) → сторона стены (`SNAP_DIST / 2 / scale`, `pointOnSegment`) → область; hover-подсветка в `ToolState` (рисует 0056).
- **Выбор**: клик по точке — точка, по стороне — стена, Ctrl+клик по стороне — вся комната; клик мимо — сброс; Esc — сброс. Где живёт выделение конструктора — по ADR E (`Editing`-состояние или `selection`).
- **Драг точки** после сдвига > 3 px (одна константа порога): снап с `exceptPoints` = перетаскиваемая точка (+ совладельцы общего id — они едут автоматически); live-позиция — в состоянии инструмента (документ не трогается до mouseUp — по ADR D/E); на mouseUp — команда `movePoints` одной записью истории; **дроп на стену** → разрез стены точкой (`splitSegment`), **дроп на точку** (манхэттен < эпсилона) → слияние (`mergePoints`) — координата после снапа финальная, без «прыжка».
- **Драг стены** по нормали: дельта курсора проецируется на перпендикуляр, оба конца сдвигаются одинаково; гайды подавлены, снап позиции учитывается; mouseUp — `moveSegment`.
- **Удаление точки** двойным кликом → `deletePoint` (слияние двух смежных стен; общий id — правило ADR D).
- **Прерывание**: Esc во время драга / blur вкладки / `pointercancel` → возврат к исходному положению, в историю ничего не пишется.
- **Нудж (решено ADR 0019 E4, в шаге 2):** стрелки/WASD двигают выделенную точку или сторону (обе точки) на шаг по `settings.units` (1 см / 0.1 см (мм), Shift ×10, Shift+Ctrl/Cmd ×0.1; имперской системы нет — решение автора 2026-08-19) — `tools.key({ kind: 'nudge', dx, dy, factor })` → `movePoints` с `coalesce: 'nudge:<ids>'` (серия = одна запись); без выделения `key` возвращает `{ handled: false }` — вьювер панорамирует. Нудж комнаты и удаление стены/сегмента целиком — **не в шаге 2** (парковка build-order).

Скоуп: состояния и переходы, хит-тест как чистые функции (`document/geometry/` или рядом со снапом), связка с командами 0055; тесты: слой 1 — хит-тест по приоритету и обе стороны каждого порога (`POINT_SIZE`, `SNAP_DIST/2`, 3 px), проекция дельты на нормаль; слой 2 — все переходы (hover → выбор → драг → дроп; дроп на стену → разрез; дроп на точку → слияние; dblClick → удаление; Esc/blur/`pointercancel` во время драга → откат без записи; смена инструмента посреди драга); одна запись истории на жест; e2e через dev-ручку: нарисовать прямоугольник → перетащить угол → комната пересобрана → undo вернул.

Не в задаче: инпуты длины ребра / ширины стены (0060); панель свойств комнаты (шаг 7); DOM-ввод и отрисовка hover/выделения (0056).

## Заметки

- Скоуп заведён до принятия ADR D/E (0052); после принятия — сверить, где живёт выделение конструктора, трогает ли live-драг документ, и форму команд 0055 — поправить этот файл.
- **Уточнено по ADR 0019/0018 (2026-08-19):** выделение конструктора — `ToolState.editing.selection: HitTarget | null` (`{ kind: 'point' | 'wall' | 'room' }`), не неймспейс `selection`; смена выделения → внутренний `history.breakSeries()`; хит-тест — чистые функции `document/geometry/hittest/` (точка `POINT_SIZE/scale` манхэттен → сторона `SNAP_DIST/2/scale` → комната), пороги в px / `viewport.scale`; **live-драг — `pointOverrides` в `ToolState`** (документ не трогается; вьювер разрешает позицию `overrides[id] ?? layout.points[id]`), на `pointerUp` — `movePoints` (дроп на сегмент — точка проецируется на него, T-стык делает `normalize`; дроп на точку — координата цели, слияние в `normalize`); драг стены — `movePoints` двух концов; dblClick — `deletePoint` (каскад D2); отмена (Esc/`blur`/`pointercancel`/Ctrl+Z во время драга/смена вида) — без записи.
- **Реализовано (2026-08-19).** Чистые функции `document/geometry/`: `hittest/hitTest.ts` — `hitTest(point, layout, rooms, viewport, { exceptPointIds, skipRooms })`, `HitTarget`, `HitRoom` (структурная проекция `DerivedRoom`), `sameHitTarget`, `POINT_SIZE = 6`, `WALL_HIT_DIST = SNAP_DIST / 2`; `edit/faceNormalShift.ts` (`faceNormal`, `shiftAlongNormal`, `shiftPoint`), `edit/nudgeStep.ts` (`NUDGE_STEP_CM`, `nudgeStep(units, factor)`). Автомат `engine/tools/`: `ToolState.ts` — `Pressed { target, origin, selected }`, `EditingState.pressed?/reclicked?`, `DraggingPointState { pointId, selection, origin, pointOverrides, snap, guides, dropTarget }`, `DraggingWallState { face, selection, grab, shift, pointOverrides, snap }`, `KeyAction | { kind: 'delete' }`; `ToolHandler.ts` — `ToolContext.derived/movePoints/deletePoint`; `editHit.ts` — `DRAG_THRESHOLD = 3`, `hitAt`, `keepTarget`, `targetAlive`, `facePoints`, `inConstructor`, `editingWith`; `editing.ts` — hover/pressed/клик/Ctrl+клик/dblClick/нудж/delete/refresh; `draggingPoint.ts`, `draggingWall.ts` — стартеры и обработчики; `ToolsNamespace.ts` — регистрация в `HANDLERS`, `derived`/`movePoints`/`deletePoint` в контексте. `index.ts` — типы `DraggingPointState`, `DraggingWallState`, `Pressed`, `HitRoom`, `HitTestOptions`; значения `sameHitTarget`, `POINT_SIZE`, `WALL_HIT_DIST`, `DRAG_THRESHOLD`. Новых команд документа нет: разрез/слияние — `normalize` (ADR 0018 D1). Ошибки команд (`movePoints`/`deletePoint`) — молча в `logger.debug`.
- **Решения в рамках/сверх ADR (вписаны в ADR 0019 «Что важно знать», уточнения 0059):** (a) `key({ kind: 'delete' })` — Delete/Backspace удаляет выделенную вершину (бриф автора; ADR ранее говорил «Delete ничего не делает» — строка ADR исправлена; сторона/комната/пусто — `handled: false`); (b) dblClick удаляет только вершину, по которой кликнули **уже выделенной** (`Pressed.selected` → `Editing.reclicked`) — закрывает развилку 0057/0058: пара кликов двойного клика, где первый завершил рисование (стены у первой/последней точки, второй угол прямоугольника, комната по точкам) или впервые выделил вершину, подтверждения не даёт, фильтр `event.detail` во вьювере не нужен; (c) Ctrl/Cmd при драге — `dropTarget = null` (ни проекции, ни координаты цели), позиция ровно сырая, слияние только при тождестве координаты; (d) клик внутри комнаты выделяет комнату; Ctrl+клик по `outer`-грани без комнаты — стена; (e) `pressed` — в состоянии (клик = два `tools:changed`); (f) выделение — на `pointerUp`, драг выделяет свою цель при входе; после отмены жеста выделение остаётся; (g) `selection` в drag-состояниях — та же ссылка, `selectionOf` → серия нуджа не рвётся входом/выходом из жеста; (h) `refresh` на `document:changed` пересчитывает hover и снимает мёртвое выделение, под драгом пропавшая вершина/грань отменяет жест; (i) вне конструктора указатель/dblClick/нудж/Delete — no-op, выделение хранится (спека 08); (j) нудж комнаты — `handled: false` (парковка ADR); (k) драг стены: снап позиции конца `a` с `exceptIds` обоих концов, снапнутое смещение проецируется обратно на нормаль (движение строго перпендикулярно), гайдов нет; (l) `hitTest` с `exceptPointIds` исключает и рёбра этих вершин (свои рёбра не цель дропа); (m) превью драга вершины = позиция дропа (проекция/координата цели на каждом кадре в `pointOverrides`) — «прыжка» на `pointerUp` нет; при слиянии выделяется выжившая вершина (меньший id, ADR 0017 C1); (n) экспорт констант хит-теста из `index.ts` — для хендлов/сравнения целей во вьювере 0056.
- **Известное ограничение (в ADR 0019):** T-стык на дропе надёжен для осевых сторон; на наклонной стороне квантованная проекция может сойти с прямой на ~5e-4 см и `normalize` разрез не сделает (точка ляжет рядом, без ошибки) — доработка `normalize`/`resplitSegments` при необходимости, парковка.
- **Находка property-теста (к 0054, не к 0059):** `sortByArea` с допуском `SORT_AREA_EPS` не задаёт строгий порядок при близких площадях — повторный `normalize` на restore может переставить контуры-близнецы: `layout` после `redo` равен закоммиченному по значению, но не по ссылке/порядку контуров; инвариант «одна запись на жест» в property проверяется без учёта порядка контуров.
- **Критики (субагенты, 2026-08-19):** по ADR — блокеров нет; учтено: dblClick через `reclicked` (сценарий «прямоугольник завершён первым кликом пары»), превью = позиция дропа, перевыбор выжившей вершины при слиянии, `targetAlive` грани в кадре драга стены, экспорт констант хит-теста; зафиксировано как ограничение — наклонный T-стык; не сделано (осознанно): снап конца `b` при драге стены (снапится только `a`, документировано), нудж комнаты. По тестам — блокеров нет; учтено: зеркальный кейс слияния (выживает id перетаскиваемой), циклическое сравнение кольца после разреза, негативные ветки порога (комната/пустота), снап-цель сбоку от нормали при драге стены, полная таблица отмен и смена инструмента/программный undo для драга стороны, nudge/delete/не основная кнопка во время драга, `pressed` без цели после удаления, не конечный нудж, tie-break и совладелец в хит-тесте, property: `pressPoint/pressFace` не трогают документ, `dragCommits` только из `editing`, инвариант «одна запись» через undo/redo, бюджет событий ужат до `pointerEvents + changes`, e2e фиксирует viewport.
