## Описание

Переписываем `PublicLayout` под четыре режима, которыми управляет страница: `guest-landing`, `auth-landing`, `app` и `auth`. Комбинация состояния сессии со свойством режима даёт четыре состояния шапки и три состояния подвала из макета.

**Шапка.** Всегда: логотип слева, высота содержимого 40px + padding 12px, снизу граница `--separator`, контейнер до 1200px, боковые поля 32px (16px до 1024px).

- `guest-landing`: навигация по секциям (`#features`, `#how`, `#faq`) + справа «Войти» (вторичная) и «Создать проект» (акцент).
- `auth-landing`: та же навигация; справа «Мои проекты» (акцент) + кнопка профиля (аватар 32px в плитке 40px + шеврон, popover-меню на клик).
- `app`: без навигации; логотип ведёт на `/projects`; справа кнопка профиля (аватар + имя + шеврон); фон под шапкой `--background`.
- `auth`: только логотип, ничего больше.

**Меню профиля.** Popover 220px, белый, радиус 12px, padding 4px, тень `0 2px 8px rgb(0 0 0 / 0.10)` + рамка 1px `--separator`, отступ 8px от кнопки, прижат к правому краю. Сверху: имя 14px/500 и почта 13px `--muted` в блоке 8px 12px. Разделитель. Пункты 36px: «Настройки» (`/settings`) и «Выйти» (вызов logout). Клик — открыть, Escape / клик вне / выбор пункта — закрыть, фокус возвращается на кнопку.

**Мобильное меню (< 1024px).** Навигация и профиль уходят в бургер 44px справа. Меню **накрывает** контент, не сдвигает: панель раскрывается под шапкой на всю ширину, страница затемняется на 40%, `body` — `overflow: hidden`. Анимация 160ms open / 120ms close, `translateY(-8px)` + `opacity`; при `prefers-reduced-motion: reduce` — мгновенно. Содержимое:

- Гость на лендинге: разделы + «Войти».
- Вошедший на лендинге: разделы + разделитель + имя с аватаром + «Выйти»; «Мои проекты» остаются кнопкой в шапке.
- В приложении: имя с аватаром + «Настройки» + «Выйти» (бургер справа заменяет кнопку профиля).

**Подвал.**

- Лендинг (`guest-landing` / `auth-landing`): развёрнутый, фон `--surface-secondary`, граница сверху `--separator`, контейнер до 1200px, padding 48px 32px, gap 32px. Сетка `1.4fr 1fr 1fr 1fr` (лого + описание + три колонки ссылок; до 1024px — одна колонка, padding 32px 16px). Заголовки колонок 11px/600 uppercase трекинг 0.06em `--muted`. Ссылки 14px `--foreground-secondary`, ховер — акцент. Разделитель 1px `--border`. Правовая строка 13px `--muted` («© {год} уютно», «Условия использования», «Конфиденциальность»). Колонка «Аккаунт»: гость — «Войти / Регистрация / Сброс пароля»; вошедший — «Мои проекты / Создать проект / Настройки».
- `app`: белая полоса, граница сверху, padding 24px 32px; слева правовая строка, справа «Написать нам».
- `auth`: только правовая строка по центру, padding 24px 32px, без границы сверху и без боковых ссылок.

**Как режимом управляют.** Ожидаемый API — `<PublicLayout mode="guest-landing" | "auth-landing" | "app" | "auth">`. `guest-landing` / `auth-landing` выбирается автоматически по состоянию сессии, поэтому страница лендинга передаёт просто `mode="landing"` (или значение по умолчанию), а компонент внутри разводит. Приложение (`/projects`) и `/settings` передают `mode="app"`, страницы аутентификации — `mode="auth"`. Точный API — в момент реализации.

**Как использовать в страницах уже сейчас.** `HomePage` — `mode="landing"`. `LoginPage`, `RegisterPage` — `mode="auth"`. Точки, где ещё нет собственных страниц (`/projects`, `/settings`), в этой задаче не задеваются — режим `app` покроется, когда появятся.

Год в подвале берётся из `new Date().getFullYear()`, не хардкодится.

## Заметки

- Кнопка «Выйти» (в popover-меню профиля и в мобильном меню) уже подключена к `authManager.logout()`, но сервер ещё не реализует `POST /api/v1/auth/logout` — метод менеджера бросает «not implemented». Вызов обёрнут в `try/catch`, ошибка логируется в консоль. Заработает автоматически, как только появится серверный эндпоинт (отдельная задача).
- Страницы `/projects` и `/settings` пока не существуют — режим `app` покроется в задачах на эти страницы; в этой задаче он реализован в компонентах, но визуально проверен не был.
- Про хидратационное расхождение id у `react-aria` (Accordion в FAQ на `/`) — предсуществующее, не связано с этой задачей, отдельно.
