## Описание

`0081` дал `persistence` механику (очередь, dirty-гейт, откладывание на drag). Эта задача наливает в неё **политику спеки 10** — таймер, гейты, ветки ошибок — и заводит ручное сохранение.

Автосейв делается **дословно по спеке 10, без ретраев и без новых триггеров** (ADR 0021). Соблазн «добавить экспоненциальный бэкофф» и «сохранять на `visibilitychange`» — вне скоупа: спека выбрала простое поведение сознательно.

### Ручной Save

- Триггеры: кнопка «Save» в шапке (её рисует `0084`) и шорткат **Ctrl+S / Cmd+S**. Перехват шортката — в клавиатурном владельце планера (`projection/input/keyboard.ts`), рядом с остальными горячими клавишами; браузерный «сохранить страницу» гасится.
- Уходит `PUT …/document` с `autosave: false`.
- **Ручной Save во время активного drag откладывается** до отпускания мыши (механика — `0081`); Ctrl+S ведёт себя так же.
- Ошибка ручного Save — **модалка** с текстом ошибки (не тост). Здесь заводится состояние и текст, сама модалка — `0084`.
- Частный случай: проект удалён во второй вкладке — сервер отвечает 404 → ошибка «Проект удалён» с кнопкой «В галерею».
- **Превью ручной Save в v0 не обновляет** — снимок превью это шаг 9. Строку спеки «только ручной Save обновляет превью» реализовать нечем; факт зафиксировать в «Заметках», не изобретая заглушку.

### Серверный автосейв

- **Периодичность — раз в 60 секунд.**
- **Таймер стартует с задержкой 5 секунд после старта редактора** (спека 10: «чтобы не молотить сохранения сразу на инициализации»).
- **Гейтов ровно два:** у проекта есть `projectId` и поднят dirty-флаг. «Текущий пользователь — владелец» спека выносит как защитный инвариант на будущее, а не как третье условие.
- **Гасителей тика тоже два:** демо-роут (серверного автосейва там нет вовсе) и активный drag/трансформация (тик пропускается тихо).
- Уходит `PUT …/document` с `autosave: true`.
- **Повтор после ошибки не безусловен**: отдельного ретрая по таймеру нет — **следующий тик через 60 с при наличии изменений** попробует сам. Иконка снимается при первом успешном сохранении.
- Ошибка автосейва — **без модалок и тостов**: тихое состояние ошибки, которое `0084` показывает иконкой предупреждения с тултипом «Не удалось сохранить на сервер, HH:MM».

### Офлайн

- Пока сети нет — состояние `offline`, которое шапка показывает **постоянным статусом** «нет сети, изменения не сохранены» (решение брифа оболочки 2026-08-20); ручной Save дополнительно поднимает модалку с тем же смыслом.
- **Обещания «изменения сохранены локально» в этих текстах нет и быть не может**: локальной копии у обычного проекта не существует. Закрыть вкладку в офлайне — значит потерять несохранённые правки; это осознанная цена решения.
- **Отдельного `online`-хендлера нет.** «Серверная синхронизация возобновляется автоматически при восстановлении сети» трактуется как **ближайший 60-секундный тик** — и это выбор ADR 0021, а не пересказ спеки: спека по офлайну недоопределена. Подписки на `window.addEventListener('online')` в коде быть не должно.
- **`beforeunload` не вешаем.**

Не в задаче: вёрстка индикатора, кнопки и модалок (`0084`); черновик демо и его таймер 30 с (`0083`); гейт Save в демо и модалка «Войдите, чтобы сохранить» (`0065`); загрузка проекта (`0085`).

## Приёмка

- [x] Ручной Save уходит с `autosave: false`, поднимает статус «идёт сохранение» и по успеху даёт «Сохранено, HH:MM» + снятый dirty.
- [x] Ctrl+S / Cmd+S запускает ручной Save и гасит браузерное сохранение страницы; во время drag — откладывается до отпускания.
- [x] Автосейв уходит **раз в 60 с** и только при обоих гейтах: без `projectId` не уходит, при снятом dirty не уходит — отдельный тест на каждый гейт.
- [x] Первый тик не раньше **5 с** после старта редактора.
- [x] Оба гасителя проверены: в режиме демо серверный автосейв не запускается вовсе; при активном drag тик пропускается тихо и не копится в очередь.
- [x] После ошибки автосейва **нет немедленного повтора**; следующая попытка — на ближайшем тике через 60 с и только при наличии изменений; при снятом dirty попытки не будет — тест на таймерах.
- [x] Успешное сохранение снимает состояние ошибки.
- [x] Ошибка ручного Save даёт состояние «модалка» с текстом; 404 от сервера даёт частный случай «Проект удалён» с действием «В галерею»; ошибка автосейва даёт **тихое** состояние без модалки — три отдельных теста.
- [x] Офлайн даёт постоянное состояние `offline`; ручной Save в офлайне дополнительно поднимает состояние модалки; ни в одном тексте нет обещания «сохранено локально».
- [x] В коде **нет** `window.addEventListener('online', …)` и **нет** `beforeunload` — проверяется тестом или грепом в приёмке.
- [x] Очередь из `0081` держится: одновременный ручной Save и тик автосейва дают один запрос в полёте.
- [x] `pnpm typecheck`, `pnpm lint`, `pnpm test` зелёные.
- [ ] Prettier чист; ровно один PR.

## Заметки

- **Превью (спека 10: «явное ручное сохранение не заменяется автосохранением — только оно обновляет превью») в v0 не реализуемо**: снимок 720×540 — шаг 9, колонка `preview` заведена пустой (`0078`). Ветку «ручной Save обновляет превью» **не имитировать**; когда придёт шаг 9, она вешается сюда же.
- **Конкурентная запись из двух вкладок** — last-write-wins без предупреждения (спека 10). `updatedAt` из ответа сервера кладётся рядом с состоянием (`0081`) и делает будущее предупреждение дешёвой добавкой, но самого предупреждения в v0 нет.
- **Откат версии старой вкладкой** закрывает сервер (`0080`, отказ на `version` ниже сохранённой), а не клиент. Клиенту достаточно показать ошибку и предложить перезагрузить страницу.
- **Индикатор без шапки не встанет.** Компонента шапки редактора в коде нет — `ProjectPage` рендерит `<Planner />` на весь экран. Эта задача сдаётся на уровне состояний и тестов движка; видимую часть делает `0084`, и её порядок относительно каркаса оболочки решается там.
