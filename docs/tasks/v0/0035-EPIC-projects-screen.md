## Описание

Личный кабинет пользователя: страница `/projects` с сеткой карточек его проектов и базовыми действиями (создать, открыть, переименовать, дублировать, удалить). Это первый экран приложения — то, куда попадает залогиненный пользователь после `/login`, `/register` или клика по логотипу.

Скоуп эпика:

- **БД**: новая таблица `projects` с минимальными полями — `id`, `user_id`, `name`, `created_at`, `updated_at`. Информация о сцене/планировке в эту итерацию не входит (см. release-v0: сцена появится в эпике редактора).
- **Бэкенд**: `ProjectsManager` + `ProjectsRepository`, REST под `/api/v1/projects` (list, create, rename, duplicate, delete), гарды `requireAuth`, регистрация в Registry.
- **Фронтенд**: страница `/projects` в `PublicLayout mode="app"`, сетка карточек с состояниями (загрузка / пусто / ошибка), плитка «Новый проект» + главная кнопка «Создать проект», модал «Новый проект» (предзаполненное имя «Квартира» → «Создать и открыть» → редирект в редактор), меню карточки и модалы «Переименовать» / «Удалить», клиентское дублирование.
- **Роутинг**: `Route.Projects = '/projects'` уже объявлен (`shared/router/routes.ts`) — подключить в `Router.tsx` под `requireAuth`.
- **Шапка/подвал**: `PublicHeader mode="app"` и `PublicFooter mode="app"` уже реализованы (задача 0026). Здесь не переделываем — только используем.

Вне скоупа v0 (и этого эпика):

- Превью-скриншот 3D-вида (`thumbnail`) — сейчас у карточки всегда заглушка (диагональный паттерн из макета). Реальный скриншот появится вместе с редактором.
- Информация о сцене (стены, мебель, камера) — отдельная таблица `project_scenes` или колонка `scene` в `projects` в эпике редактора.
- Пагинация, поиск, сортировка, папки, шеринг, фильтры — не входят в v0 (см. `projects-screen.md`).
- «Посмотреть пример» → `/demo` — кнопка на пустом состоянии ведёт на `/demo`, но сам демо-проект в этом эпике не делаем.

## Приёмка

- [ ] Залогиненный пользователь на `/projects` видит свою сетку проектов, счётчик, кнопку «Создать проект» и (последней) плитку «Новый проект».
- [ ] Неавторизованный редиректится на `/login?from=/projects` (SSR + клиент).
- [ ] Полный цикл: создать (через модал «Новый проект» → редирект в редактор) → открыть меню → переименовать → дублировать → удалить работает без перезагрузки страницы (кроме шага создания, где мы уводим пользователя в редактор — это ожидаемо).
- [ ] Состояния «загрузка», «пусто», «ошибка загрузки» отрисованы согласно `projects-screen.md`.
- [ ] Модалы имеют корректный фокус-менеджмент (Escape закрывает, фокус возвращается к инициатору), поле «Название» получает фокус и `select()` при открытии, валидация только на отправке.
- [ ] Адаптив: до 1024px колонка контента 560px, кнопка «Создать проект» уходит под заголовок, меню карточки — bottom sheet, модалы прижаты к низу.
- [ ] Все подзадачи `[x]`.
