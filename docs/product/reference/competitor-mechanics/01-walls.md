# 01 — Создание и редактирование стен

> Реверс из `plannercore.js` (не минифицирован). Единицы — см; экранные пороги — px, делятся на зум `WC.wallsEditor.scale`. Модель **контур-first**: пользователь рисует замкнутые контуры, стены регенерируются из них. См. `00-overview.md`.

## Interaction (state machine)

Редактор — конечный автомат на `WC.wallsEditor`; `WC.StateEditing` (стр. 64529) — idle/hover-хаб, диспатчит в состояния правки и создания.

### Состояния создания

**`StateMakingWalls` (65855)** — полилиния «стены с толщиной».

- `start()`: создаёт `CRawContour`, ставит `currentPt` в снапнутый курсор, `me.wallsWidth = 10` см (офсет толщины на одну сторону от центральной линии), эмитит `STATE_MAKING_WALL`.
- `mouseMove`: `currentPt` = снапнутая позиция; до 3-й точки `calcStart()` (66024) авто-выбирает сторону офсета (`signSide = ±1`) по наименьшему углу к соседним сегментам; после 3-й точки фиксирует (`fixedStart = true`).
- `mouseUp` (постановка): **замыкает** петлю, если `euclDist(lastPt, cur) ≤ wallsWidth` ИЛИ `euclDist(firstPt, cur) ≤ 0.1`; иначе добавляет точку. На замыкании `stop()` конвертит контур в блоки комнаты (`WC.drawTool.blocksFromContour(pts, signSide*wallsWidth, startNeighbSeg)`, 57922), создаёт `CRoom`ы, затем `rebuildWallsAndCovers()`.
- `dblClick`: no-op (завершение только через замыкание петли).
- Клавиши: **Esc** отмена (`cancelMake`), **Ctrl+Z/Y** undo/redo (undo убирает последние 2 точки; стек `undoPoints`).
- Live-размеры: длина каждого ребра рисуется; редактируемый инпут показывается только если ребро на экране ≥ 45 px (для замыкающего прямоугольника ≥ 70 px). Пунктирные зелёные «выравниватели» тянутся к победившей цели снапа.

**`StateMakingRoom` (66624)** — та же полилиния, но **без толщины** (нулевой band); требует `TR.contourValid(points)` и ≥ 4 точки; замыкается при `manhDist` к первой/последней ≤ eps.

**`StateMakingRect` (65560)** — клик-1 = `startPt`, клик-2 = `endPt`; `findBoxes` строит 4 угла. Если оба размера > `2 × wallsWidth` — полая комната (8 точек: внешний+внутренний контур), иначе сплошная 4-точечная. Инпуты размеров скрыты ниже 70 px.

**`StateMakingArea` (65197)** — зона с низким потолком (заливка `rgba(0,255,0,0.1)`); отклоняет область, если пересекается с существующей (`TR.compareContours != OUTSIDE && != CONTACT`).

### Состояния правки

- **`StateEditing` (64529)** приоритет хит-теста: (1) ближайшая точка комнаты в `POINT_SIZE/scale`; иначе (2) сторона стены через `pointOnLine` с точностью `SNAP_DIST/2/scale`; иначе (3) область/внутренность. На `mouseDown` взводит `pointDown`/`sideDown`; драг начинается только после сдвига > `POINT_SIZE/2` px (`CLICK_SHIFT = 3` px) → `StateDraggingPoint`/`StateDraggingWall`. `mouseUp` по стороне выбирает стену (или всю комнату при зажатом **Ctrl** → `StateSelectedRoom`). Удаление точки — **в два клика** (`dblClickToDel`) → `WC.core.delPoint`.
- **`StateDraggingPoint` (64013)**: `currentPt.move(snap.x, snap.y)`; т.к. `CPoint.move` двигает и `children[]` (точки пола на тех же координатах), привязанная геометрия следует автоматически. `exceptPts` = перетаскиваемая точка + её дети (чтобы не снапнуться к себе). На дропе → `rebuildWallsAndCovers()` + save. **Слияние на дропе** неявное: после move `resetWalls`/`connectAllPoints` пере-выводят стены из нового контура, совпадающие точки (`manhDist < L_EPS`) сливаются.
- **`StateDraggingWall` (64292)**: двигает весь сегмент **перпендикулярно** себе — дельта курсора проецируется на перпендикуляр стены (`ptDir2 = perpendicularPoint(A, B, 100)`), оба конца двигаются одинаково.

## Snapping & constraints

Движок снапа — `WC.snapTool` (`WC.SnapTool`, ~57221). Каждое состояние зовёт `getSnapPoint(P, exceptNodes, WC.SNAP_DIST/scale, farNodes)` (57568). Все дистанции — **Манхэттен** (`TR.manhDist`). Флаги: `pointsSnap=true`, `pointsAlign=true`, `orthoAlign=false` (H/V орто-лок, кнопка «выровнять по осям»), `bisectorAlign=true`.

**Приоритет (первое совпадение выигрывает, 57629–57696):**

1. **К существующему углу** — ближайший из `allPoints` в `snapDist` (`snapToNearest`). При `pointsSnap=off` радиус сжимается до 2 units.
2. **Перпендикулярное X+Y** — есть и X-, и Y-выравниватель → снап в их пересечение (`snapPerpendicular`/`snapX`/`snapY`).
3. **Биссектриса ∩ ось** — на линию биссектрисы угла, пересечённую с X/Y-выравнивателем (принимается только если в `snapDist`).
4. **Орто ∩ биссектриса**.
5. **Одиночная ось** (X или Y).
6. **Только орто** — H/V-лок относительно предыдущей точки `rawCont` (`orthogonalSnap`).
7. **Только биссектриса** — проекция на биссектрису двух сегментов у ближайшего угла (`bisectorSnap`; радиус поиска `snapDist × 10`, отказ если перпендикулярное расстояние > `snapDist`).

Результат округляется до 0.001 см. `snapX/snapY` учитывают только точки в кадре, если не переданы явно как `farNodes`.

**Ограничения/отказы:** `MIN_WALL_LENGTH = 15` см, `MAX_WALL_WIDTH = 80` см; вырожденные/дубли-точки отбрасываются в `stop()`; `TR.contourValid` / `TR.contourSelfIntersected` отклоняют самопересечения; мин. экранный размер для инпута длины — 45 px.

## Data model

- Стена **не хранит явное поле толщины**. `DataWall` (52759): `point1/point2` (концы центральной линии), `height` (280), `materialID` + `addMaterialID` (доп. финиш), `materialRotation/X/Y`, `faceRight` (какая сторона к комнате). Толщина — это `wallsWidth` контура (10 см), применённый как **офсет между внешним и внутренним контуром комнаты**; band стены — область между ними. Митры углов возникают неявно из `blocksFromContour` (офсет полилинии + стыковка соседних band) и триангуляции комнаты — отдельной процедуры митринга нет.
- Комнаты **выводятся**: `rebuildWalls` (59582) → `TR.rebuildContours` (триангуляция + трассировка, 51094) возвращает внешние контуры, дырки, группы треугольников. `CRoom`/`CPoint` пересоздаются каждую правку; старые `data` комнаты пере-привязываются по перекрытию площади (`compareContoursByArea == INTERSECT`).
- `resetWalls` (60139) регенерит `CWall`: для каждой стороны комнаты матчит старую стену (по концам `match`, либо `pointOnLine` когда сторона — под-сегмент длинной старой стены — так работает **разрезание стены точкой**) и копирует `data`. `delPoint` (59361) убирает угол и, если он соединял ровно две стены, **сливает** их в одну `CWall` с data одной стороны.
- `connectAllPoints` пере-привязывает точки пола к совпадающим точкам комнаты в `L_EPS`.

## Geometry rebuild (2D + 3D)

- **2D:** план перерисовывается из контуров `CRoom` и offset-band стен каждый кадр; размеры/выравниватели поверх.
- **3D:** `WC.createWall3D(wall, defHeight)` → `DataWall.build3D()` (53070): строит 4 вектора углов (`y=0` низ, `y=height` верх; z = −y), считает длину и `areaRect = height × length`, триангулирует прямоугольник грани `[A,B,C,D]` в локальных координатах (длина, высота) с **вычтенными дырками** проёмов (см. `02-doors-windows.md`). Сдвиг граней на 0.1 см (`faceRight ? −0.1 : 0.1`) против z-fighting. Каждый материал — своя «часть» с вершинами/UV; часть по умолчанию (id −1) — остаток.
- Детекцию комнат триггерит `me.core.rebuildWallsAndCovers()` (59533) — в конце каждого drag точки/стены, каждого `stop()` make-инструмента и каждого дропа проёма.

## Wall properties (editing)

Через состояния выбора: `materialID` на сторону + `addMaterialID` (финиш), `materialRotation`, `materialX/Y` (`setMaterial`, `setMaterialRotation`, `setMaterialShift`), `height` (на стену; 280). Толщина правится на уровне контура/комнаты (`wallsWidth`), не на `DataWall`.

## Edge cases

- Петля замыкается по близости к **последней** точке (≤ толщина) ИЛИ к **первой** (≤ 0.1) — поддержка и «закончить здесь», и «защёлкнуть».
- Авто-детект `signSide` замораживается после 3-й точки, чтобы band не перевернулся посреди рисования.
- Дубли концов контура убираются в `stop()`.
- Самопересекающиеся/невалидные контуры отбрасываются.
- Матч под-сегмента в `resetWalls` сохраняет материалы при разрезе стены новым углом.
- Два клика на удаление угла — защита от случайного удаления.
- Кандидаты снапа ограничены видимым кадром для перфа; явный `farNodes` — оверрайд.

## Confidence & gaps

- **Точно из кода:** все состояния и пороги, лесенка снапа, `DataWall.build3D`, регенерация `rebuildWalls/resetWalls`, константы, триангуляция с дырками (не CSG).
- **Inferred (средняя уверенность):** толщина = per-contour `wallsWidth=10 см` офсет (у стены нет явного поля толщины — сильно подразумевается `blocksFromContour(pts, signSide*wallsWidth)`, но точная математика митров живёт внутри `blocksFromContour`/`rebuildContours`, не прослежена до конца).
- **Не найдено:** внутренности `blocksFromContour` (точный митринг/стыки).
